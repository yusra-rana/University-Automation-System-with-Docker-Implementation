# University Automation System (UAMS)

A database-focused University Automation Management System developed as part of Advanced Database Management Systems (ADBMS) coursework, using Docker and Microsoft SQL Server.

## Overview

The University Automation Management System (UAMS) is an academic project focused on working with database management, administration, and SQL Server through practical lab implementations.

The project uses Docker to set up and manage a SQL Server environment, providing hands-on experience with containerized database systems.

## Technologies & Tools

- **Docker** – Containerization and database environment setup
- **Microsoft SQL Server** – Database management
- **SQL** – Database queries and operations
